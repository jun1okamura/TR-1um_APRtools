# セルライブラリ `v59_4`

`TR-1um_cells.lef` / `TR-1um_STDCELL.gds` から生成。**行高は全て 59.4 µm、サイト 5.4 µm。**

> **PDK 同梱の `TR-1um_STDCELL.gds`（105 セル）とは別物。** `pdk/README.md` §2 参照。

ABC に SR ラッチを勝手に組ませないため。

### `BUFTH` — シュミットトリガのしきい値（メモ）

入力パッドはすべてこれで受ける（`apr/insert_bufth.py` が P&R 前に挿入。
`docs/11_frame_io.md` §4）。

| | 値 | 条件 |
|---|---:|---|
| VT+（立上り） | **3.709 V** | typ モデル / VDD 5.0 V / 25 °C |
| VT−（立下り） | **1.201 V** | 同上 |
| ヒステリシス | **2.508 V** | VT+ − VT− |

**条件を書かずにこの数字を出さないこと。** プロセスコーナーは振っていない
（PDK にモデルカードが 1 枚しか無い。U13）ので、**typ 1 点の値**である。

この値が根拠になっている所:

| 使い先 | どう効くか |
|---|---|
| Liberty `input_voltage (BUFTH_in)` の `vih`/`vil` | 合成と STA が読む。`char/mklib.py` の `SCHMITT` が書き出す |
| `A` ピンの遅延表 | 入力しきい値がライブラリ共通の 50 % と違うので、**入力遷移の軸で吸収**させている。`BUFTH` の遅延値を他セルと同じ感覚で読まないこと |
| `charlib.CELL_SLEWS` | 鈍い縁が来るセルなので `BUFTH` だけ入力遷移を 1000 ns まで測る |
| IRSIM で `BUFTH` を迂回する判断（U14） | 帰還が解けず X から抜けない。`docs/40_gotchas.md` §1-6b |

**測り直し方**（2026-09-17 に追加。それまで測り直す手段が無かった）:

```sh
python3 char/char_schmitt.py BUFTH
```

DC 掃引は履歴を持てないので、**準 DC の三角波**（片道 200 µs = セル本来の
遷移 ~1 ns の 2×10⁵ 倍）で 0 → VDD → 0 と往復させ、出力が VDD/2 を横切った
瞬間の**入力電圧**を拾う。`mklib.py` の定数との差も一緒に出る。
`--deck-only` でデッキだけ見られる。

> ★ この値は 2026-09-17 まで `char/mklib.py` に**直書きの定数**で、
> 「DC で往復させて測った実測値」と書いてあるだけだった。デッキもログも
> リポジトリに無く、**測り直せなかった**（U95）。
> **根拠にする数字は測り直せるようにしておく**（U45）。

回路としては、入力側の PMOS 2 段直列（vdd→n7→n6）と NMOS 2 段直列
（n6→n3→vss）に、帰還の PMOS（n7—vss、ゲート n6）と NMOS（vdd—n3、ゲート n6）が
付いた素直な CMOS シュミット。出力段 `n6 → Y` は普通のインバータ。
**帰還が自分の出力ノード n6 でゲートされている**のがヒステリシスの源で、
同時に IRSIM が解けない理由でもある。

## 2. 物理セル

| セル | 幅 (µm) | サイト | 用途 |
|---|---:|---:|---|
| `FILL1` | 5.4 | 1 | 純フィラー（容量なし）。**既定では無効** |
| `FILL2` | 10.8 | 2 | デキャップ（2 Tr）。**サブサーキット呼び出し**で LVS に出す |
| `FILL3` | 16.2 | 3 | デキャップ。**優先 M2 コリドー用の既定セル** |
| `TAP2` | 10.8 | 2 | ウェル／基板タップ。縦 M2 電源ストラップを持つ |
| `TAP2S` | 10.8 | 2 | 列端用タップ（`CLASS BLOCK`） |
| `TAP3` | 16.2 | 3 | タップ |

- **`FILL3` を優先コリドーに使う理由**: `FILL2`（2 トラック）だと上側トラックの via パッド
  （半幅 1.7 + 隙間 2.0）が隣のセルへ 1.0 µm はみ出し、隣に M2 があると実質 1 本しか使えない。
  `FILL3`（3 トラック）なら真ん中の 1 本が必ず両側とも空く
- **`FILL1` は既定オフ**（`APR_USE_FILL1=1` で有効）。入れると隙間の刻みが変わって配置が
  丸ごと変わる。v64_8 にあった「5.4 µm ちょうどの隙間が作れない」制約は `FILL1` で消える
- `TAP2` は **`TAP_PITCH = 534.6 µm`（= 5.4 × 99）以内**で並べる（`docs/03_core_geometry.md` §2）
- `TAP2` はデバイスを持たないので **LVS ソースには出さない**。`FILL2`/`FILL3` は出す

`MEMPORT`（`TR-1um_PNR.{gds,lef}` のみ）= `REG8x16` を R90 して水平パッド列に変換した
P&R 専用マクロ（1598.4 × 502.2）。詳細は `macro/regfile/07_memory_array.md`。

**タイミング規則**: `ADDRB` は `ADDR` より INV 1 段（約 1.2 ns）遅れるので、アドレス遷移中に
2 行が同時選択される瞬間がある。リードは無害だが**ライトは致命的** →
**アドレス確定 → `WEB` 立下げ → `WEB` 立上げ → 次のアドレス**の順を守る。

## 4. 電源ピン名

**`vdd` / `vss`（小文字）。** `DEC0` / `DEC2` はウェル／基板タップを持たないので
`vnw` / `vsub` を加えた **4 本**になる。

## 6. ラベル整備の残り

- `REG4x16` のトップピン未ラベル（`ADDR[3:0]` / `WEB` / `DD[3:0]` / `Q[3:0]` / `vdd` / `vss` を (49,1) に）
- `TLAT` の `WR` / `WRB` / `RD` / `RDB` が (48,1) にある → **(49,1) へ**
- `DEC0` / `ADDBUF` の信号ラベルにテキストが無い

> ラベルは **(48,0) / (49,0) だけ**が DRC / LVS に読まれる（`docs/10_pdk_facts.md` §2）。

## 7. `v64_8`（凍結）との差

`docs/02_stdcell_diff.md`。要点は「**論理セルの幅は全て同一、違うのは行高・電源ピン名・
FF の内部ピン・Liberty の質**」、および v64_8 の `BUF_X4` / `BUF_X16` は
**LEF に MACRO があって GDS に実体が無い**（使うと黙って `BUF_X1` になる）。
